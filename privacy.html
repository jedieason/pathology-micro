Micro — 隱私權政策 (Privacy Policy)

最後更新日期：2026 年 9 月

1. 個人資訊收集與使用

Micro（以下簡稱「本應用程式」）尊重並重視使用者的個人隱私。本應用程式不會收集、儲存、傳輸、出售或分享任何使用者的個人身分識別資訊（PII）。所有使用者的作答內容、學習紀錄與錯題標記均僅儲存於使用者個人的本機裝置（Local Storage / SharedPreferences）。

2. 網路連線與資料傳輸

本應用程式僅在需要同步公開病理教學題庫與載入病理切片照片時，連接至官方 GitHub 遠端儲存庫（jedieason/pathology-micro）。本應用程式不會收集任何裝置診斷資訊、分析追蹤數據或使用者行為軌跡。

3. 第三方服務與廣告

本應用程式不包含任何第三方廣告 SDK、分析統計套件或追蹤程式碼。

4. 聯絡方式

若您對本隱私權政策有任何疑問或建議，歡迎至 GitHub 儲存庫建立 Issue 與我們聯繫：
https://github.com/jedieason/pathology-micro/issues
